AGGIORNAMENTO SU GITHUB PAGES
1. Apri il repository GitHub Fiffy360 dal tuo iPhone.
2. Entra nella cartella principale (root).
3. Scegli Add file > Upload files.
4. Estrai questo ZIP sul dispositivo e seleziona i sei file contenuti (non caricare il file ZIP come unico file).
5. Conferma il commit sulla branch main. Se GitHub chiede di sostituire i file omonimi, conferma.
6. Attendi la pubblicazione di GitHub Pages, poi apri https://fiffi1609.github.io/Fiffy360/ in Safari e aggiorna la pagina.
7. Se la vecchia versione resta visibile, chiudi completamente Safari e riapri; il service worker v3 aggiorna la cache.

INSTALLAZIONE
Safari > Condividi > Aggiungi alla schermata Home.

FUNZIONI DISPONIBILI IN QUESTA VERSIONE
Home con riepilogo, attività, agenda con esportazione .ics, acqua, check-in umore,
pasti settimanali, lista spesa, diario, riepilogo serale, registrazione allenamenti,
progressi corporei, ciclo e check-in benessere, backup/ripristino JSON.

LIMITI IMPORTANTI
I dati vengono salvati localmente nel browser e NON sono cifrati end-to-end né sincronizzati
su cloud. Evita password, credenziali bancarie o dati estremamente sensibili.
L'assistente AI non è ancora collegato a un modello; Face ID nativo, cassaforte password,
Siri avanzata, notifiche push affidabili, Apple Health e sincronizzazione bidirezionale
del Calendario richiedono backend, autorizzazioni e/o un'app iOS nativa. L'esportazione
.ics consente di importare singoli appuntamenti in Calendario Apple.
