FIFFY360 – anteprima PWA

Questa cartella contiene una prima interfaccia web installabile come PWA dopo la pubblicazione su un hosting HTTPS.

PUBBLICAZIONE CON GITHUB PAGES
1. Caricare TUTTI i file di questa cartella nella cartella principale del repository GitHub "Fiffy360".
2. Aprire Settings > Pages.
3. In Build and deployment selezionare Deploy from a branch.
4. Selezionare branch main e folder /(root), quindi Save.
5. Attendere la pubblicazione. L'indirizzo sarà simile a https://NOMEUTENTE.github.io/Fiffy360/ .
6. Aprire l'indirizzo in Safari su iPhone > Condividi > Aggiungi alla schermata Home.

IMPORTANTE
Questa è una demo iniziale. Le attività, il diario e alcuni check-in vengono salvati solo nel browser di questo dispositivo (localStorage); non sono sincronizzati o sottoposti a backup.
Non inserire password reali: la Cassaforte è solo una schermata dimostrativa e non salva credenziali.
L'interfaccia AI è dimostrativa: non è collegata a un modello AI.
Face ID, cifratura della cassaforte, notifiche affidabili, sincronizzazione Apple Calendar, backup cloud, HealthKit e integrazione Siri/Comandi Rapidi richiedono sviluppo e servizi aggiuntivi. Non sono attivi in questa demo.
